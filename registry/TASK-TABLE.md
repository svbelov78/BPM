# Таблица реестра задач

Источник: [Products BPM — Таблица](https://www.figma.com/design/tOFCfQUjfFvAB0Pgqxb9xQ/Products-BPM?node-id=137-12975).

Обновление от 29.09.2026:

- Шапка — 56 px, все подписи Small R 13/18, без принудительных переносов.
- Строка — 180 px. Названия задачи и процесса — Simple SB 17/24; описание, участники, даты и статус — Simple R 17/24.
- Колонки образца шириной 1485 px: 326 / 328 / 248 / 129 / 132 / 161 / 161 px.
- Метаданные задачи и ID процесса — отступ сверху 24 px. Названия, инициатор, дата создания и срок — 56 px; группа ответственных — 63 px; статус — 55 px.
- Срок в таблице показан без «до». Карточки используют прежнее поведение.
- ФИО инициатора и группа аватаров ответственных видны при любой ширине. ФИО и статус переносятся без обрезки; заголовок «Ответственные» не заменяется на «Отв.». В группе сохраняется обычное обозначение дополнительных участников «+N».
- Между 1193 и 1485 px колонки плавно сжимаются до 248 / 206 / 192 / 129 / 120 / 149 / 149 px. Ниже 1193 px используется локальный горизонтальный скролл, без скрытия людей или сжатия аватаров. Скелетон следует тем же правилам.
- `assets/tasks/table-sort.svg` — оригинальный чёрный SVG из образца Figma. Сборщик включает его в автономный HTML.

Реализация: `task-visuals.css`, `task-visuals.js`.

Проверки:

```sh
node registry/test-task-table-style.cjs
node registry/test-task-card-footer.cjs
node registry/build-standalone.cjs
BPM_TASK_TABLE_FILE=Sber-BPM-Registry-Standalone.html node registry/test-task-table-style.cjs
node registry/test-standalone.cjs
```

Команды запускаются из корня пакета, рядом с автономным HTML и папкой `registry`.

Проверка сохранения ФИО и аватаров использует изолированный браузер и локальный HTTP-сервер: запустите `python3 -m http.server 8766 --bind 127.0.0.1` из корня пакета, затем `BPM_TASK_TABLE_URL=http://127.0.0.1:8766/registry/index.html node registry/test-task-table-people.cjs`. Для автономной сборки замените URL на `http://127.0.0.1:8766/Sber-BPM-Registry-Standalone.html`.
