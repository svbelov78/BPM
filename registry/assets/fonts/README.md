# SF Pro — локальный ресурс

Предоставлен пользователем в `SFPro_Sergei.zip` 10.10.2026 после его подтверждения отдельного разрешения на встраивание. Затем владелец отдельно подтвердил разрешение на публичное распространение шрифта вместе с HTML после предупреждения о публичности `svbelov78/BPM` и запросил загрузку текущего снимка. Это подтверждение владельца предоставленных материалов, а не общее исключение в лицензии Apple. Дальнейшие публикации и развёртывание сайта требуют нового запроса.

- Оригинал: `SFPro_Sergei/SF-Pro.ttf`, 21 249 904 байта.
- SHA256 оригинала: `26e2ab7338d25b79276b9363f22bb7576850f7f326a8fb97ba2419cf0f923012`.
- Ресурс: `sf-pro-variable.woff2`, 8 192 808 байт.
- SHA256 ресурса: `3c7de0dbfd9087f7d022bfae668aff6e3c6d2551968bcad7757d0b44b95744ae`.
- Подготовка: FontTools 4.66.1, Brotli 1.2.0, `registry/prepare-sfpro.py`; только перекодирование TTF → WOFF2, без сабсеттинга/удаления символов.
- Сохранены все 10 240 символов и 35 571 глиф; оси `wght` 1–1000 (400 по умолчанию), `wdth` 30–150 (100), `opsz` 17–28 (28).

В CSS зарегистрирован как `BPM SF Pro`, чтобы не совпадать с установленными шрифтами. Здесь только используемое прямое вариативное начертание; неиспользуемые italic/rounded/статические файлы из архива не копируются. Обычная сборка использует уже готовый WOFF2 и не требует Python или FontTools.
